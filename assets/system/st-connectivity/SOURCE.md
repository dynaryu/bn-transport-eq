# Source

**Algorithm.** Standard graph reachability. Implemented over `networkx`
(BSD-3-Clause), using union-find on the induced subgraph of usable links.

- networkx: https://networkx.org — version pinned in `environment.yml`.

**Provenance of this asset.** No external dataset. The algorithm is textbook and
the implementation is ours, so there is nothing to cite beyond networkx itself.

**Topology is not part of this asset.** The graph comes from the knowledge graph
at compile time (`Network` and its topology predicates). This asset is the
operator, not the network.

**Retrieved / written.** 2026-10-04.
